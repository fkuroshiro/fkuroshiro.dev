# Security Policy

## Reporting a vulnerability

If you find a security issue on fkuroshiro.dev, please report it privately to
<hello@fkuroshiro.dev> instead of opening a public issue. I will reply as soon as I can.

Please include the affected URL, what you observed, and steps to reproduce it.

## Scope

This is a personal portfolio website. Only the production site at
<https://fkuroshiro.dev> is in scope.
